Falta conectar tu base de datos

Este catálogo guarda todo en Firebase (gratis, sin tarjeta). Configúralo una sola vez:

  1. Ve a console.firebase.google.com → crea un proyecto (nombre libre).
  2. Dentro del proyecto, clic en el ícono </> (Web) para agregar una app. Ponle un nombre y copia el bloque firebaseConfig que te muestra.
  3. Abre este archivo HTML con un editor de texto y pega ese bloque donde dice PEGA_AQUI_TU_FIREBASE_CONFIG.
  4. En el menú lateral de Firebase entra a Firestore Database → Crear base de datos → modo producción.
  5. Pestaña Reglas: pega las reglas que te di aparte y publica.
  6. Guarda el archivo y súbelo a GitHub Pages. Listo.

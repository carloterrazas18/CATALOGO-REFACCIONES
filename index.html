Falta conectar tu base de datos

Este catálogo guarda todo en Firebase (gratis, sin tarjeta). Configúralo una sola vez:

  1. Ve a console.firebase.google.com → crea un proyecto (nombre libre).
  2. Dentro del proyecto, clic en el ícono </> (Web) para agregar una app. Ponle un nombre y copia el bloque firebaseConfig que te muestra.
  3. Abre este archivo HTML con un editor de texto (Bloc de notas sirve) y pega ese bloque donde dice PEGA_AQUI_TU_FIREBASE_CONFIG, cerca del inicio del archivo.
  4. En el menú lateral de Firebase entra a Firestore Database → Crear base de datos → modo producción → cualquier ubicación.
  5. Dentro de Firestore, pestaña Reglas: borra lo que hay y pega las reglas que te di aparte (documento "reglas-firestore.txt"). Clic en Publicar.
  6. Guarda el archivo HTML y súbelo a GitHub Pages (o cualquier hosting estático). Listo — el link ya funciona para todos.

Una vez configurado, este mensaje desaparece solo.
